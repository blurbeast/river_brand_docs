# Riverbrand Banking System

## The Definitive Knowledge Book

> **One banking engine. Two reading tracks. Every reader finishes with the same map.**

Welcome to the authoritative knowledge book for the **Riverbrand Banking Engine** (`RiverbrandBE`) — a modular, ledger-first core banking platform built on Node.js 20, Fastify, TypeScript, PostgreSQL 15, Redis 7, and Docker.

This is a textbook, not a wiki. It is written for two audiences at once:

- **The Non-Technical Track** — executives, founders, investors, product managers, operations teams, and compliance officers who want to understand what this bank does, why it was built this way, and where it is going — in plain language, with real stories and relatable diagrams.
- **The Technical Track** — architects, backend engineers, SREs, security auditors, and newly onboarded developers who need the real mechanism: concurrency guards, ledger invariants, the service map, the job fleet, and the runbooks.

Every technical chapter has a non-technical twin covering the same ground. You are never more than one cross-link away from the other side of the aisle.

## The Method

Every chapter follows one pedagogy — **Learn, Unlearn, Relearn**:

1. **Unlearn** the naive mental model ("a bank is a balance number in a database").
2. **Learn** the real forces: concurrency, immutability, idempotency, provider failure, regulatory ceilings.
3. **Relearn** how Riverbrand answers them — and why the answer holds under load.

The full method lives in [How to Read This Book](front-matter/f05-how-to-read.md); every chapter echoes it in a three-line recap.
